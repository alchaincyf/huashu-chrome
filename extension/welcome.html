扩展装好了，还差一步

lingee-chrome 让你的 AI agent 用这个浏览器干活，带着你已有的全部登录。

  1. ✓

    浏览器扩展

    已经装好了。
  2. 2

    在终端里跑一行，接上你的 agent

    它会自动找到你电脑上装着的 AI agent，逐个配好。需要先装 Node.js（20 以上）。
    npx -y lingee-chrome@latest install
    等待本地端连上…（agent 第一次用它时会自动拉起）
  3. 3

    对你的 agent 说一句

    重启 agent 后，试试这样说：
    用 lingee-chrome 打开小红书，看看我最近一篇笔记的数据
  4. 4

    想看它在做什么，点工具栏的头像

    侧栏会显示它正在操作哪一页、准备做什么、刚刚做了什么。建议把图标固定到工具栏：点地址栏右边的拼图图标，再点 lingee-chrome 旁边的图钉。
卡住了？在终端跑 npx lingee-chrome doctor，它会告诉你卡在哪一步。
