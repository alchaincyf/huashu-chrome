SEC.01

装上扩展

3 STEPS · ≈40s
01FIG.1.1

打开商店页

点下面这个按钮，商店页在新标签页里打开。认准发布者是 huasheng.ai、图标是右边这个卡通头像。

添加至 Chrome ↗

chromewebstore.google.com/detail/foiljmaplphdfimfcnfdpekhdnfbgfbf

02FIG.1.2

点「添加扩展程序」

Chrome 会在右上角弹一个确认框，把它要的权限列给你看。点橙色那颗按钮，几秒就装完了。

权限只用于操控你打开的标签页，不上传任何数据。

03FIG.1.3

看工具栏：灰点消失

装好后图标出现在工具栏。图标右下角有灰点，说明还没连上本机的桥；灰点消失、图标恢复正常，就是接通了。

图标被 Chrome 收进了拼图菜单？点拼图图标，把 huashu-chrome 钉出来。

04FIG.1.4 · 验证

跑一次体检，确认整套跑通

回到终端，敲这条命令。看到 「握手正常 · Chrome 扩展在线」就成了——MCP server、本机的桥、Chrome 扩展三段都通了，可以直接让 agent 开始干活。

没看到？点工具栏的 huashu-chrome 图标 →「重连」，几秒后再跑一次。

FIG.2 · 可见性

FIG.2 — 被 agent 操控中的 Chrome：人眼看得见的四个信号

  • A被操控的标签页会进一个彩色标签组组名「花叔」，组色就是这次会话的身份色——同时开两个 agent 也分得清谁在动哪个。
  • B页面四边同色描边 + 呼吸泛光的箭头光标光标滑到哪，就是它正在动哪。描边一收，说明这一页它松手了。
  • C右下角驾驶舱正在做什么 / 准备做什么 / 最近时间线。不用猜它在想什么。
  • D需要人帮忙时弹浮条验证码、扫码、付款确认这类只能你来的事，它停下来等你，你处理完它接着走。
NB 新标签页一律在后台打开，不抢你的焦点。它干它的，你该干嘛干嘛——这是这个扩展从第一行代码起就守着的规矩。

附录 A 开发者手动加载 商店打不开，或者你已经 clone 了仓库——四步，看图就够
A.1
打开扩展管理页

网页不许直接跳 chrome:// 开头的地址，只能你自己粘进地址栏。Edge 用 edge://extensions，Brave 用 brave://extensions。

A.2
右上角打开「开发者模式」

开关在这一页的右上角。打开它，页面上会多出一行按钮。

A.3
点「加载已解压的扩展程序」

左起第一颗按钮。点开会弹出文件选择框。

A.4
把扩展文件夹拖进来

回终端跑 npx huashu-chrome extension --reveal，扩展文件夹会在访达 / 资源管理器里被选中。把它拖到扩展管理页上就装好了；或者在 A.3 弹出的选择框里选中它。这一页不放路径——它在你自己的终端里。

手动加载的扩展 ID 和商店版一致：{{EXT_ID}}。装完同样回终端跑一次 npx huashu-chrome doctor。改过扩展代码的话，回 chrome://extensions 点一次「重新加载」，再刷新目标页面。
