# 12306（kyfw.12306.cn）· 查票不用登录

实测 2026-09-03。

**查余票和查票价都不需要登录态**，但**必须在浏览器里发请求**（要 cookie）；
`curl` 直连拿不到，会返回 `{"c_url":"leftTicket/queryG","status":false}` 或空。

## 打开列表页（带查询参数）

```
https://kyfw.12306.cn/otn/leftTicket/init?linktypeid=dc&fs=<出发中文名>,<电报码>&ts=<到达中文名>,<电报码>&date=YYYY-MM-DD&flag=N,N,Y
```

`fs`/`ts` 是「中文名,电报码」，中文要 URL 编码。

## 真正好用的是页内直调 API

⚠️ `eval` **不会 await Promise**，直接 `fetch(...).then(...)` 返回 `{}`。
→ **两步走**：先把结果塞进 `window.__x`，下一个 `eval` 读 `window.__x`。
isolated world 的全局变量在同一 tab 内跨 eval 保留。

### 余票

```js
(window.__r='p',fetch('/otn/leftTicket/queryG?leftTicketDTO.train_date=YYYY-MM-DD&leftTicketDTO.from_station=XXX&leftTicketDTO.to_station=YYY&purpose_codes=ADULT',{credentials:'include'})
 .then(r=>r.json()).then(j=>{window.__r=j.data.result.map(s=>s.split('|')).map(a=>
   [a[3],a[6],a[7],a[8],a[9],a[10],'一等:'+a[31],'二等:'+a[30],'tn:'+a[2],a[16]+'-'+a[17],a[35]].join('~')).join('\n')}),'go')
```

`result` 每行是 `|` 分隔的数组，用得上的下标：

| 下标 | 含义 |
|---|---|
| 2 | `train_no`（查票价要用） |
| 3 | 车次 |
| 6 / 7 | 出发站 / 到达站**电报码** |
| 8 / 9 / 10 | 发车 / 到达 / 历时 |
| 16 / 17 | `from_station_no` / `to_station_no`（查票价要用） |
| 30 / 31 | 二等座 / 一等座余票（`有` / 数字 / `候补` / `无`） |
| 35 | `seat_types`（查票价要用，如 `9MOO`） |

`j.data.map` 是电报码→中文站名的字典，**用它反查站名，别自己猜**。

### 票价（余票接口不含价格，必须单独查）

```js
fetch(`/otn/leftTicket/queryTicketPrice?train_no=${tn}&from_station_no=${f}&to_station_no=${t}&seat_types=${st}&train_date=YYYY-MM-DD`,{credentials:'include'})
```

返回里 `O` = 二等座、`M` = 一等座、`A9`/`9` = 商务座、`WZ` = 无座。
可以 `Promise.all` 一次批量查十几个车次。

## 站码坑

**城市码会把同城各站全部返回**，同城多站必须用下标 6/7 二次过滤。电报码不能靠拼音猜，
同城的几个站往往毫无规律（同一个城市里，主站、东站、南站的三字码常常互不相干）。
拿不准就查 `j.data.map` 字典，或先用一次列表页看它回了哪些站。

⚠️ **离目的地最近的车站未必有车**：实测有的近郊高铁站全天只有 1 班开往某个方向。
**先查再规划，别看地图想当然。**
