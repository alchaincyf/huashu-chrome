# 搜狗微信搜索（weixin.sogou.com）

实测 2026-09-03，本机 curl 带 UA 即可，免登录。

- `weixin?type=2&query=<词>` 返回「找到约 N 条结果」+ 首页 10 条
  （`div.txt-box` 里 `<h3>` 是标题）。**N 可以当话题饱和度用**——同一批词里
  几百条和一百多条的差别是真实的，可以判断「这个话题有多少号在写」。
- ⚠️ **加引号精确搜必 0 结果**，所以「一篇文章被转载了多少次」这条路走不通；
  索引本身也不全，明确存在的原文经常搜不到。
- 账号名不在 `class="account"` 里，混在 `div.s-p` 中且带 `document.write(timeConvert…)`
  脚本残留，解析前要先剥 `<script>`。
- 结果不带阅读 / 在看数。它只回答「这话题有多少号在写」，不回答「谁写火了」。
